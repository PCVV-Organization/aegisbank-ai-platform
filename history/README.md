# Historial de AegisBank AI Platform

Este directorio conserva evidencia, prompts y material de exploración que no forma
parte de la lectura operativa ni del contexto LLM predeterminado. Cada archivo
describe un momento del proyecto; el código, las pruebas y las guías activas tienen
precedencia.

- `briefings/`, `career/`, `charter/`, `chatgpt-prompts/`, `experiments/` y
  `research/`: contexto histórico y material de aprendizaje.
- `quality/` y `evaluation/`: informes y salidas fechadas; no acreditan el estado
  del checkout actual.
