# AegisBank Teaching Contract

Every AegisBank implementation report is also a lesson for a learner starting from zero.
For each new acronym or technical concept, explain:

1. Full name and Spanish translation.
2. Meaning and internal operation.
3. Problem solved and why AegisBank uses it.
4. Concrete repository example.
5. Main alternative and when not to use it.
6. Typical risks and failure modes.
7. Relation to Mibanco responsibilities.
8. Relation to Microsoft AI-103 or AI-200.
9. Evidence level: `LAB-COVERED`, `CI-CONFIGURED`, `CLOUD-PENDING`, or `PROD-PARTIAL`.

Reports must distinguish executed evidence from configuration. A local workflow file is
`CI-CONFIGURED / RUNNER-PENDING`; it is not proof that GitHub Actions executed.
Never claim production, cloud, compliance, or certification from laboratory evidence.
