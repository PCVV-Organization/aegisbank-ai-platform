## Capability Decision

The final release must not claim that blocked or cloud-pending capabilities are
implemented in production. The complete classification is maintained in
`docs/requirements/V1.0-MATURITY-MATRIX.md`.

The Docker blocker is reproducible and documented: the local Docker Linux
engine was unavailable, so the image-presence acceptance could not pass. This
prevents claiming a clean all-infra release on this machine.

## Interview Evidence
