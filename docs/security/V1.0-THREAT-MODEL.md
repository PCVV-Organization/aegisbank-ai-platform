# v1.0 Threat Model

**Method:** STRIDE (Spoofing, Tampering, Repudiation, Information disclosure,
Denial of service, Elevation of privilege), applied to local laboratory trust
boundaries. This is not a certification or a claim of production security.

| Boundary | Threat | Control | Residual status |
|---|---|---|---|
| User -> Agent | prompt injection, spoofing, sensitive input | structured prompts, deterministic policy, redaction | local covered; model attacks remain monitored |
| Agent -> Tools/MCP | unauthorized tool or malformed arguments | canonical registry, schemas, ownership policy, MCP contracts | `TESTED-LOCAL` |
| RAG -> Answer | poisoned or stale evidence | trust labeling, citation validation, abstention | `TESTED-LOCAL`; cloud index pending |
| HITL -> WRITE | approval tampering or replay | payload digest, expiry, actor/action binding, idempotency | `TESTED-LOCAL` |
| HOTL -> WRITE | unsafe operator state | kill-switch checked before every WRITE | `TESTED-LOCAL` |
| App -> Config/Secrets | secret disclosure or configuration drift | separated providers, fail-fast validation, no secret logging | local covered; Key Vault identity `CLOUD-PENDING` |
| App -> Messaging | duplicate, loss, poison event | transactional outbox, idempotent consumer, DLQ | `TESTED-LOCAL`; broker cloud pending |
| Data stores | cross-customer access | ownership filters and authorization tests | `TESTED-LOCAL` |
| Runtime | outage, timeout, resource exhaustion | bounded retries, timeout, circuit breaker, moderate local test | local covered; capacity unproven |

## Release Controls

- Do not promote if ownership, HITL/no-write safety, tool routing, or
  idempotency invariants regress.
- Treat audit and OTel records as minimized operational evidence, not a copy of
  prompts, secrets, or unrestricted banking payloads.
- Keep cloud identity, managed services, remote CI execution, and production
  load evidence explicitly `CLOUD-PENDING`.
