## Dated status note — 2026-09-21

The findings and release status in the referenced
[baseline closure report](../../history/quality/LOCAL-BASELINE-CLOSURE-20260921.md)
are a snapshot from 2026-09-21. The dispatcher and regression tests were later
updated; the old live trajectories do not represent those later changes. Use
the current checkout and the dated capability matrix to establish present
behavior. This document is a local laboratory threat model, not current runtime
evidence or a release certification.

**Method:** STRIDE (Spoofing, Tampering, Repudiation, Information disclosure,
Denial of service, Elevation of privilege), applied to local laboratory trust
boundaries. This is not a certification or a claim of production security.

## Phase-2 Red-Team Boundary

`docs/security/PHASE2-LOCAL-RED-TEAM-EVIDENCE.md` records the bounded local extensions
(Phase 2.1 direct/mutation and Phase 2.2-R1 live pgvector XPIA & tool-output injection).
The `ASR = 0%` claim applies strictly to the evaluated fixed regression and local suites
under `phi-4-mini` targeting real banking tools (`get_my_loans`, `get_loan_details`,
`create_service_request`). High-volume multi-seed generative evaluations, adaptive attack
corpora, and cloud Foundry red teaming remain unproven.

Evaluation distinguishes execution-boundary enforcement (forced `score=1.0` to guarantee
untrusted context reaches the model) from corpus poisoning discoverability (unforced dense
embeddings in `pgvector`, where the poisoned chunk naturally ranked 2nd with cosine 0.8347).
Every observation records complete tool trajectories (`tools_available`, `tools_requested`,
`tools_denied`, `tools_executed`) with normalized arguments and customer binding.

The canonical invariant registry is the briefing's §6.6 table (`I_1` through `I_15`).
Phase 2.2-R1 live XPIA and tool-output cases exercise `I_1` through `I_4` and `I_7`; `I_5` and
later invariants require their respective transactional, reliability, or observability journeys.

## Release Controls

- Do not promote if ownership, HITL/no-write safety, tool routing, or
  idempotency invariants regress.
- Treat audit and OTel records as minimized operational evidence, not a copy of
  prompts, secrets, or unrestricted banking payloads.
- Keep cloud identity, managed services, remote CI execution, and production
  load evidence explicitly `CLOUD-PENDING`.
