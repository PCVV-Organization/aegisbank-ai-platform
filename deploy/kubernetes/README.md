# Kubernetes Laboratory Manifests

These manifests describe a Kubernetes laboratory configuration; they do not establish that a cluster exists or that deployment has been performed.

Before any apply operation, verify the exact kubeconfig context, namespace, image, and target resources, and confirm that the action is explicitly authorized. Do not create paid AKS resources from this guide. Follow the local-first promotion boundary in [deployment guidance](../README.md) and the application [AGENTS.md](../../AGENTS.md).
