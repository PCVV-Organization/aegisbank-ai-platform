fix(auth): expose cross-origin CSRF nonce

Purpose
Allow the separated Static Web App to send the CSRF double-submit header when the API session cookie belongs to a different origin.

Changes
- include the non-secret CSRF nonce in the synthetic login response
- keep the session token HttpOnly and never expose it to browser JavaScript
